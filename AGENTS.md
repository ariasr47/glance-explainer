# HTML explainer maintenance

- This checkout is the source of truth for this plugin. On Rodrigo's machine it is installed as a Claude Code plugin from the GitHub marketplace (`html-explainer@html-explainer-skill`, user scope); the former junction at `~/.claude/skills/html-explainer` was retired on 2026-10-07. After pushing a release, update the installed copy with `claude plugin marketplace update html-explainer-skill` and `claude plugin update html-explainer@html-explainer-skill`, then restart.
- Each skill folder under `skills/` is self-contained (Agent Skills layout: `SKILL.md`, `references/`, `assets/`, `scripts/`, `examples/`). Skills name files by paths relative to their own `SKILL.md`; gather and atlas reach the core skill through `../html-explainer/`. Never point a skill at `docs/`, `tools/` or anything outside `skills/`.
- Preserve existing user changes, including edits to `template.html`. If the template's `<style>` or `<script>` changes, paste both blocks into `gallery.html`.
- Before committing, run `node tools/check-repo.mjs` (exit 0 required; CI runs it too). For page or design changes, also open the page once in a browser at 390 px and desktop width, light and dark. The checker needs Node 18 or newer and no packages.
- A design canvas is a design record, not a live reference. When its build ships, save its source in `docs/dev/design/`, or in the private explainer-eval repository when it holds private content, and mark its proposal or spec as shipped. See `docs/dev/design/README.md`.
- Update `.claude-plugin/plugin.json` and `.claude-plugin/marketplace.json` together when plugin metadata changes, and add a `CHANGELOG.md` section for every version. Local metadata is not evidence that a release was published.
- The public site (`docs/index.html`, `docs/roadmap.html`, the gallery and the examples) deploys to GitHub Pages from `main` through `.github/workflows/ci.yml`.
- The portfolio catalog at `C:\Dev\agent-skills\catalog` holds a frozen 0.1.0 snapshot whose build script expects the pre-1.4.0 layout. Do not regenerate it from here without Rodrigo's go.
