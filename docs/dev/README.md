# Development history

Plans, proposals, research, assessment scenarios and screenshots from building the plugin. Nothing here is needed to use it.

Files keep the paths they had when they were written. Before release 1.4.0 the template, gallery and guides lived in a top-level `assets/` folder and the scripts in `scripts/`; the [changelog](../../CHANGELOG.md) maps every old path to its new one.

| Folder | What it holds |
|---|---|
| `plan/` | Build specs for each release |
| `proposals/` | Design proposals, including parked ones |
| `research/` | Research that shaped the visuals and the roadmap |
| `scenarios/` | Prompts used to assess the plugin across audiences and page types |
| `explainers/` | Explainer pages about the plugin, made with earlier versions |
| `shots/` | Screenshots recorded as release evidence |
| `parked/` | Withdrawn work, kept with the reason and what would restore it |
